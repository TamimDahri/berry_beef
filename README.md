# Berry Beef – cameronstrawberry.com

Landing page for Berry Beef: Cameron Highlands strawberries delivered in Kuala Lumpur every Wednesday.

Plain HTML, CSS and JavaScript with no build step, so it can be hosted on Cloudflare Pages as-is
(build command: none, output directory: `/`).

- `index.html` – the page
- `site.css` – styles (colours and type taken from the Berry Beef logo)
- `site.js` – WhatsApp order links and the "next delivery" countdown (Malaysia time)
- `images/` – logo and product photos

To change the WhatsApp number, edit `WHATSAPP_NUMBER` at the top of `site.js`.
